## Descripción

Este repositorio contiene cinco programas desarrollados en Python para practicar el uso de los ciclos `for` y `while`.

1. **Contador de dígitos:** cuenta la cantidad de dígitos que contiene un número entero mediante un ciclo `while`.
2. **FizzBuzz:** imprime los valores del 1 hasta un número indicado y sustituye los múltiplos de 3, 5 o ambos por las palabras correspondientes.
3. **Número invertido:** invierte los dígitos de un número entero utilizando operaciones aritméticas y un ciclo `while`.
4. **Suma de pares e impares:** calcula por separado la suma de los números pares y la de los impares desde 1 hasta `n`.
5. **Pirámide de asteriscos:** dibuja una pirámide centrada de asteriscos con la altura proporcionada por el usuario.

## Ejecución

Para ejecutar cualquiera de los programas, se debe tener Python 3 instalado y utilizar en una terminal un comando como el siguiente:

```bash
python 01_contador_digitos.py
```
